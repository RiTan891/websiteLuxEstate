## 🔧 Настройка

### Добавление новых квартир

В JavaScript-коде найдите массив `apartments` и добавьте новый объект:

```javascript
{
    id: 6,  // Уникальный ID
    title: {
        ru: 'Новая квартира',
        en: 'New apartment'
    },
    city: 'moscow',  // moscow, spb, sochi
    price: 350000,   // Цена в долларах
    area: 75,        // Площадь в м²
    rooms: 2,        // Количество комнат
    floor: 6,        // Этаж
    totalFloors: 15, // Всего этажей
    balcony: true,   // Наличие балкона
    view: {
        ru: 'Вид на город',
        en: 'City view'
    },
    infrastructure: {
        ru: 'Развитая инфраструктура',
        en: 'Developed infrastructure'
    },
    parking: true,   // Наличие парковки
    renovation: {
        ru: 'Евроремонт',
        en: 'European renovation'
    },
    images: [
        'https://example.com/photo1.jpg',
        'https://example.com/photo2.jpg'
    ]
}
```

### Изменение цветовой схемы

В CSS найдите `:root` и измените переменные:

```css
:root {
    --beige-light: #faf6f0;  /* Основной фон */
    --accent: #b8956e;       /* Акцентный цвет */
    --text-primary: #2c2420; /* Основной текст */
}
```

### Настройка языков

Для добавления нового языка:

1. Добавьте переводы в каждый элемент с атрибутами `data-ru` и `data-en`
2. Добавьте новый атрибут `data-XX` для нового языка
3. Обновите функцию `updateLanguage()`

|------|-----|----------|
| `id` | number | Уникальный идентификатор |

| `floor` | number | Этаж |
| `totalFloors` | number | Всего этажей |
| `balcony` | boolean | Наличие балкона |
| `view` | object | Вид из окон (RU/EN) |
| `infrastructure` | object | Инфраструктура (RU/EN) |

| `renovation` | object | Тип ремонта (RU/EN) |
| `images` | array | Список URL фотографий |

### Хранение данных

- **Квартиры**: в JavaScript-массиве
- **Избранное**: в localStorage
- **Пользователи**: в localStorage
- **Сессия**: в localStorage
