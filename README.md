# LuxEstate — Premium Real Estate Website

Современный двуязычный веб-сайт для продажи элитных квартир с поддержкой английского и русского языков.

---

## О проекте

LuxEstate — это платформа для продажи элитной недвижимости. Сайт разработан с учетом современных тенденций веб-дизайна и обеспечивает удобный интерфейс для поиска и просмотра квартир.

---

## Функциональность

### Двуязычность
- Кнопка переключения RU/EN в шапке сайта
- Мгновенное переключение без перезагрузки страницы
- Полный перевод всех элементов интерфейса

### Поиск и фильтрация
- По городу: Москва, Санкт-Петербург, Сочи
- По цене: минимальная и максимальная
- По количеству комнат: 1, 2, 3, 4+
- По площади: минимальная площадь в м²

### Карточки квартир
Каждая карточка содержит:
- Фотографию объекта
- Название на двух языках
- Цену в долларах США ($)
- Площадь (м²)
- Количество комнат
- Этаж и этажность
- Наличие балкона
- Вид из окон
- Инфраструктуру района
- Наличие парковки
- Тип ремонта

### Страница деталей
- Галерея фотографий
- Полные характеристики объекта
- Описание инфраструктуры
- Кнопка связи с агентом
- Добавление в избранное

### Избранное
- Добавление и удаление квартир
- Просмотр списка избранного
- Сохранение в localStorage
- Быстрый доступ к понравившимся объектам

### Авторизация
- Регистрация новых пользователей
- Вход в систему
- Личный кабинет
- Сохранение сессии

### Просмотр фотографий
- Модальное окно для фото
- Кнопки масштабирования
- Полноэкранный режим
- Закрытие по клику

## Настройка

### Добавление новых квартир
В JavaScript-коде найдите массив apartments и добавьте новый объект с полями: id, title, city, price, area, rooms, floor, totalFloors, balcony, view, infrastructure, parking, renovation, images.

### Изменение цветовой схемы
В CSS найдите :root и измените переменные --beige-light, --accent, --text-primary.
